A tiny program that writes the GPS's one-line excuse for sending a driver down the wrong road — in the GPS's own voice, smug and defensive, blaming everyone but itself — to `entry.txt`.

## Run it

```sh
python3 main.py
```

This writes a single line of plain text (116 characters, no trailing newline) to `/output/entry.txt`. Running it twice produces byte-identical output.
